콘크리트 압축강도 예측 (Concrete Compressive Strength)

2026 하계 AI 특강 · Day 1 AutoML

----------------------------------------------------------------
1. 개요
----------------------------------------------------------------

- 내용: 콘크리트 배합비·양생기간과 실측 압축강도
- 출처: UCI #165 (Yeh 1998, 실험 데이터)
- 규모: 1,030행 · 9열 · 결측 없음 · 전부 수치형
- 유형: 회귀
- 예측 대상: 압축강도 (MPa)


----------------------------------------------------------------
2. 왜 이 문제인가
----------------------------------------------------------------

- 배합만으로 강도 예측 → 실험 횟수 절감, 최적 배합 탐색
- 강의 사례 연결: 15p 합금 설계 (배합 → 물성, 같은 구조)
- 전처리할 것이 거의 없어 '도메인 파생 변수' 실습에 최적


----------------------------------------------------------------
3. 컬럼 구성
----------------------------------------------------------------

- Cement                시멘트 (kg/m³)
- Blast Furnace Slag    고로슬래그 (0=미사용)
- Fly Ash               플라이애시 (0=미사용)
- Water                 물
- Superplasticizer      고성능감수제 (0=미사용)
- Coarse Aggregate      굵은 골재
- Fine Aggregate        잔골재
- Age                   양생 기간 (일)
- 예측 대상: 압축강도 (MPa)

※ 원본 컬럼명이 길고 단위 포함 → 아래 4번에서 정리


----------------------------------------------------------------
4. 불러오기
----------------------------------------------------------------

- 원본이 .xls → CSV 변환 또는 read_excel

    import pandas as pd

    df = pd.read_csv("concrete.csv")   # 또는 read_excel(".xls")

    # 컬럼명 정리 (순서는 head로 확인 후)
    df.columns = ["cement","slag","fly_ash","water",

    print(df.shape)          # (1030, 9)


----------------------------------------------------------------
5. 주의
----------------------------------------------------------------

[ EDA / 판단 참고 ]

① 0이 실제 값 (위장 결측 아님)
   증상: slag, fly_ash, superplasticizer의 0은 '미사용'
   → 결측으로 바꾸지 말 것

② (핵심) 도메인 파생 변수
   증상: 개별 재료량보다 '물-시멘트비'가 강도를 좌우
         모델이 비율을 스스로 못 만들 수 있음
   해결:
        df["water_cement_ratio"] = df["water"] / df["cement"]
        df["binder"] = df["cement"]+df["slag"]+df["fly_ash"]
        df["water_binder_ratio"] = df["water"] / df["binder"]
   → 파생 변수 추가 전후 성능 비교

③ 소규모(1,030행) → 파운데이션 모델 강점
        TabularPredictor(label="strength").fit(
            train, hyperparameters={"TABPFNV2":{}, "MITRA":{}})
