----------------------------------------------------------------
1. 개요
----------------------------------------------------------------

- 내용: 전남 광양 제철공장 15분 간격 전력 소비 기록
- 출처: DAEWOO Steel (한국) / UCI #851 / 한국전력, 2018
- 규모: 35,040행 (365일×96) · 11열 · 결측 없음
- 유형: 시계열 예측 (회귀)
- 예측 대상: Usage_kWh (전력 사용량)
- 특징: 국내 데이터 · 집계·공변량·누수 실습에 최적


----------------------------------------------------------------
2. 왜 이 문제인가
----------------------------------------------------------------

- 제철은 에너지 다소비 산업 → 피크 억제로 요금 절감
- 한전 요금제: 부하 유형별 단가·최대수요전력 기본요금
- 강의 사례 연결: 따릉이(시간별 수요)
- 집계 방식 실습에 최적 (15분→시간→일, 변수별 다름)


----------------------------------------------------------------
3. 컬럼 구성 (11열, 실측 확인)
----------------------------------------------------------------

[ 시점 ]
- date               15분 간격 ("01/01/2018 00:15", %d/%m/%Y %H:%M)
- NSM                자정 이후 초 (900~86400, 순환 변수)

[ 전력 — 예측 대상 및 관련 ]
- Usage_kWh                              전력 사용량 (target)
- Lagging_Current_Reactive.Power_kVarh   지상 무효전력
                                         ※ 이 컬럼만 '.' 포함(5절 ①)
- Leading_Current_Reactive_Power_kVarh   진상 무효전력
- Lagging_Current_Power_Factor           지상 역률(%)
- Leading_Current_Power_Factor           진상 역률(%)

[ 환경 — 누수 주의 ]
- CO2(tCO2)          배출량 (Usage_kWh와 상관 0.988 → 누수, 5절 ②)

[ 시간·부하 (범주, 미래도 아는 값) ]
- WeekStatus         Weekday / Weekend
- Day_of_week        Monday ~ Sunday
- Load_Type          Light_Load / Medium_Load / Maximum_Load

※ 결측 0건. 전부 실제값.

5. 주의
----------------------------------------------------------------

[ 오류는 없지만 잘못 학습/처리되는 것 ]
   (컬럼명은 4번에서 정리한 이름 기준)

① 집계는 변수마다 다름 (가장 중요)
   증상: 전부 합계 내면 "하루 평균 역률 3200%" 같은 무의미값
   해결:
        daily = df.set_index("date").resample("D").agg({
            "usage_kwh":"sum", "lag_reactive":"sum",
            "lead_reactive":"sum", "co2":"sum",
            "lag_pf":"mean", "lead_pf":"mean",
            "week_status":"first", "day_of_week":"first",
            "load_type": lambda s: s.mode()[0],   # 하루 3종 → 최빈값
        }).reset_index()
   ※ 사용량·무효전력·CO2=합계, 역률=평균, 요일=first
   ※ load_type은 하루 안에 3종 다 나옴 → first 아닌 최빈값(mode)

② CO2 누수 (상관 0.988로 확인됨)
   증상: CO2 = 사용량 × 배출계수 → 넣으면 정답 알려주는 셈
   해결:
        df[["usage_kwh","co2"]].corr()   # 0.988 → 누수
        df = df.drop(columns=["co2"])

③ NSM 순환 변수
   증상: 900초(00:15)와 86400초(24:00)가 실제 인접인데 최대 거리
   해결 (삼각함수):
        import numpy as np
        rad = 2*np.pi*df["nsm"]/86400
        df["nsm_sin"], df["nsm_cos"] = np.sin(rad), np.cos(rad)
   ※ 일별 집계 시 NSM은 무의미 → 제외

④ 공변량: 미래도 아는 값 지정
        known = ["week_status","day_of_week"]
        predictor = TimeSeriesPredictor(
            prediction_length=14, target="target", freq="D",
            known_covariates_names=known).fit(train_data)
   ※ load_type은 부하 유형별 사용량 범위가 겹침(단순 파생 아님)
     → 누수는 아니나, 미래 값을 알 수 있는지는 판단 필요


[ EDA / 판단 참고 ]

⑤ 전기 변수(무효전력·역률) 서로 강한 상관 → 조합 비교
⑥ 시계열 하나(공장 1개) → 다중 시계열은 PJM으로
⑦ 1년치(2018) → 연 주기 1번뿐 (계절성 학습엔 부족)
⑧ 결측 0건 → 전처리보다 집계·누수·공변량에 집중
