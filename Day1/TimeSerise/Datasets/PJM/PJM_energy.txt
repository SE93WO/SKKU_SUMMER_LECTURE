1. 개요
----------------------------------------------------------------

- 내용: 미국 동부 지역송전기구(PJM) 시간별 전력 소비량(MW)
- 출처: PJM 공식 + Kaggle(robikscube/hourly-energy-consumption)
- 파일: pjm_hourly_est.csv (전체 지역 통합, wide 형식)
- 규모: 178,262행 · 13열 · 1998~2018 (시간별)
- 유형: 시계열 예측 (회귀)
- 예측 대상: 전력 소비량 (MW)
- 특징: 다중 시계열(지역 11개 + 초기 전체부하) — 따릉이 못 다룬 부분


----------------------------------------------------------------
2. 왜 이 문제인가
----------------------------------------------------------------

- 전력은 저장 어려움 → 수요 예측이 발전·거래 계획의 핵심
- 다중 시계열: 지역 모델 vs 전역 모델 비교 (강의 63~64p)
- 강의 사례 연결: 따릉이(시간별 수요), 51p 응급실 수요


----------------------------------------------------------------
3. 컬럼 구성 (13열, 실측 확인)
----------------------------------------------------------------

통합 파일 pjm_hourly_est.csv 는 wide 형식:

- Datetime            관측 시각 (시간별)
- 지역 11개 (MW)      각 지역이 관측 안 된 기간은 빈칸(NaN)

[ 지역별 관측 기간·규모 (실측) ]
  컬럼      기간                  평균 규모
  PJME      2002-01 ~ 2018-08     32,080 MW  ← 동부 전체(최대)
  AEP       2004-10 ~ 2018-08     15,500 MW
  NI        2004-05 ~ 2011-01     11,702 MW  ← 2011년 종료
  COMED     2011-01 ~ 2018-08     11,420 MW
  DOM       2005-05 ~ 2018-08     10,949 MW
  FE        2011-06 ~ 2018-08      7,792 MW
  PJMW      2002-04 ~ 2018-08      5,602 MW  ← 서부
  DEOK      2012-01 ~ 2018-08      3,105 MW
  DAYTON    2004-10 ~ 2018-08      2,038 MW
  DUQ       2005-01 ~ 2018-08      1,659 MW
  EKPC      2013-06 ~ 2018-08      1,464 MW  ← 가장 짧음
  → 규모 최대 22배 차이(PJME vs EKPC), 시작·종료 제각각

[ 주의: PJM_Load 컬럼 (13번째) ]
- 지역이 아니라 초기 전체 부하 (1998-04 ~ 2002-01)
- 다른 지역과 기간이 안 겹침 (2002년 전에만 존재)
- → 지역 시계열에 섞으면 안 됨. 보통 제외 (5절 ①)


----------------------------------------------------------------
4. 불러오기 (통합 파일 → 다중 시계열)
----------------------------------------------------------------

    import pandas as pd
    from autogluon.timeseries import TimeSeriesDataFrame

    df = pd.read_csv("pjm_hourly_est.csv", parse_dates=["Datetime"])
    print(df.shape)          # (178262, 13)

    # PJM_Load 제외 (초기 전체부하, 지역 아님)
    df = df.drop(columns=["PJM_Load"])

    # wide → long (지역 = item_id), 빈칸 제거
    long = df.melt(id_vars="Datetime", var_name="item_id",
                   value_name="target").dropna(subset=["target"])

    # 일별 합계 집계 (전력량은 누적 → sum)
    long = (long.set_index("Datetime")
                .groupby("item_id")["target"]
                .resample("D").sum().reset_index())
    long.columns = ["item_id", "timestamp", "target"]

    ts = TimeSeriesDataFrame.from_data_frame(
        long, id_column="item_id", timestamp_column="timestamp")
    ts = ts.convert_frequency(freq="D")    # 빈 시점 채움

- 단일 지역만 쓰려면 melt 전에 컬럼 하나만 선택
  (예: df[["Datetime","PJME"]] — 따릉이 실습 재현)

5. 주의 — 그냥 넣으면 문제 되는 것 (해결 코드 포함)
----------------------------------------------------------------

[ 오류는 없지만 잘못 처리되는 것 ]

① PJM_Load 컬럼 제외 (지역 아님)
   증상: 13번째 PJM_Load는 1998~2002 초기 전체부하
         지역 시계열에 섞으면 기간·의미가 안 맞음
   해결:
        df = df.drop(columns=["PJM_Load"])

② wide 형식 → long 변환 필요 (통합 파일의 핵심)
   증상: 지역이 컬럼으로 나열됨 → 그대로는 다중 시계열 안 됨
   해결: melt로 지역을 item_id 행으로 (위 4번)

③ 집계는 합계 (전력량)
   증상: 평균 내면 '시간당 평균'일 뿐, 하루 총량 아님
   해결: resample("D").sum()  (위 4번)

④ 지역별 관측 기간 다름 → 빈 시점
   증상: 시작·종료 제각각 (NI는 2011년 종료, EKPC는 2013년 시작)
   해결:
        long.dropna(subset=["target"])       # melt 후 빈칸 제거
        ts = ts.convert_frequency(freq="D")  # 규칙화로 채움
   확인:
        long.groupby("item_id")["timestamp"].agg(["min","max","size"])

⑤ 지역 스케일 22배 차이 (PJME 32,080 vs EKPC 1,464 MW)
   증상: 전역 모델이 큰 지역에 치우칠 수 있음
   해결: 규모 비슷한 지역끼리 묶어 학습한 경우와 비교


[ EDA / 판단 참고 ]

⑥ 지역별 기간 먼저 확인 (위 ④ 코드)
   → PJME·PJMW는 2002년부터 길고, EKPC·DEOK는 짧음
⑦ 공변량 없음 (기온 등) → 달력 정보만 파생 가능
        long["dayofweek"] = long["timestamp"].dt.dayofweek
⑧ 계절성 이중: 연(여름 냉방·겨울 난방 피크) + 일(시간별 쓸 때)
⑨ 시간별 그대로 쓰면 지역당 10만 행대 → 일별 집계 권장
